# 经验来源与参考文件

本 skill 根据多轮论文精读汇报及修订经验整理。公开版本保留可迁移的方法、案例和参考文件，不依赖私人会话、论文库或机器路径。

## 经验案例

| 论文案例 | 提炼的经验 |
| --- | --- |
| Coded Beam Training | Spark、准确贡献定位、关键公式、实际探测过程、LLR 软信息和完整口播 |
| Channel Deduction | 总体图与内部模块图、历史与当前融合、输入输出关系和实验原因 |
| Near-Optimal Near-Field Beam Training | posterior 与目标区别、保证范围、计算费用、箭头与裁切修正 |

| AMBER | training-only 分支、预测时点、组合消融、备注同步 |
| ChannelLM | PL 与 CSI 两路径、场景划分、实测范围、表格自动增高 |

具体经验见 [lessons.md](lessons.md)。案例用于提醒核验哪些细节，不为其他论文提供科学事实。

## 方法来源

流程吸收了问题优先、Challenge–Insight–Mechanism、Claim–Evidence，以及信息、目标、资源和泛化检查等论文解构方法；视觉与文字要求来自具体的学术汇报修订经验。

本 skill 自带完成任务所需的核心说明，不要求安装其他个人 skills。PPT 的制作与导出遵循当前可用的 Presentations 能力；旧参考不冻结工具版本、任务页数或科学内容。
